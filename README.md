# EcoPonto App ♻️

Aplicação interativa desenvolvida em Python e Streamlit para mapeamento, localização e descarte correto de resíduos e entulho em Juiz de Fora (DEMLURB).

## 🚀 Funcionalidades
- Mapeamento e consulta dinâmica de ecopontos da cidade.
- Filtro inteligente por bairros e categorias de resíduos aceites (construção civil, podas, volumosos, recicláveis).
- Interface ágil e amigável, orientada à usabilidade da população.

## 🛠️ Tecnologias Utilizadas
- **Python**
- **Streamlit**
- **Pandas**

## 💻 Como Executar

```bash
cd "Aplicativo EcoPonto"
pip install streamlit pandas
streamlit run app_ecoponto.py
